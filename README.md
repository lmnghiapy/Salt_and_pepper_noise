# Salt-and-Pepper Noise

## Overview

This project implements a Salt-and-Pepper Noise model for functional simulation and verification using ModelSim.

Salt-and-pepper noise is a type of image noise that randomly changes pixel values to black or white, creating a noisy image appearance.

## Features

- Models salt-and-pepper noise for image processing applications.
- Supports functional simulation and verification using ModelSim.
- Demonstrates noise generation by modifying pixel values under configurable noise conditions.
